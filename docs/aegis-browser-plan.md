## 1. Executive Summary

Aegis Browser는 앱 실행과 동시에 사전에 허용된 VPN 노드·포트 후보를 측정하여 최적 연결을 선택하고, 암호화 터널이 정상 확인된 뒤에만 브라우징을 허용한다. 종료 시에는 터널, 라우팅, DNS 및 방화벽 설정을 원상 복구한다. 광고·트래커, 팝업, 악성·피싱 URL 차단도 기본 탑재한다.

### 권고안 요약

| 항목 | 초기 권고 |
| --- | --- |
| MVP 스택 | Electron + Chromium |
| 상용화 핵심 | Windows 네이티브 터널 서비스, OS 킬스위치, DNS 누수 방지 |
| 초기 범위 | Windows, 한국어, 서울·도쿄·싱가포르 3개 노드 |
| 초기 가격 | 월 6,900원 / 연 59,000원 / 7일 무료 체험 |
| 베타 | 30~50명 폐쇄 베타 → 200명 유료 공개 베타 |
| Chromium 직접 포크 | PMF 이후 재검토 |

## 2. 제품 비전

보안 도구를 공부하지 않아도, 브라우저를 여는 행동 하나만으로 안전한 연결과 깨끗한 웹 환경을 제공한다.

- **슬로건**: 브라우저를 여는 순간, 보호가 시작됩니다.
- **핵심 가치**: 자동성, 신뢰성, 속도 체감, 광고 없는 집중, 개인정보 최소 수집
- **포지셔닝**: 고급 브라우저가 아니라 *자동 보호 경험*을 판매하는 구독형 프라이버시 도구

## 4. MVP 필수 기능

- 주소창, 검색, 탭, 다운로드 등 기본 브라우징
- 실행 시 최적 VPN 노드 자동 선택 및 연결
- 실패 시 다음 후보 자동 전환
- 종료 시 터널·라우팅·DNS 원복
- VPN 미연결 시 외부 요청 잠금 (킬스위치)
- 광고·트래커·팝업 차단
- 로컬 악성 호스트 및 서버 측 URL 평판 조회
- OS 보안 저장소 기반 키 보관
- 연결 지역·보호 상태·차단 수 UI

## 5. 기술 전략 및 아키텍처

### 5.1 초기 구성

| 계층 | 구성 요소 |
| --- | --- |
| Desktop Client | Electron + Chromium + WebContentsView |
| Native Tunnel Helper | Windows Service |
| VPN | WireGuard |
| Blocking | Ghostery 호환 필터 |
| Threat Guard | 로컬 캐시 + 서버 프록시 URL 평판 조회 |
| Control Plane | 인증, 결제, 장치, 키 발급, 노드 디렉터리 |
| Data Plane | 지역별 WireGuard Gateway + 내부 DNS |

### 5.2 Chromium 포크 결정 기준

Electron은 빠른 출시와 기존 TypeScript 자산 활용에 유리하다. Chromium 직접 포크는 보안 패치와 빌드 인프라 유지 비용이 크므로, 다음 중 하나가 확인될 때 재검토한다.

- 유료 사용자 3,000명 이상 확보
- 호환성·성능 문제가 매출을 실질적으로 제한한다는 데이터 확보

## 6. 보안·개인정보 원칙

- Electron UI를 관리자 권한으로 실행하지 않는다.
- 터널이 확인되기 전과 끊긴 동안 신규 외부 요청을 차단한다.
- 장치별 키와 토큰은 OS 보안 저장소에 저장한다.
- 방문 URL, 검색어, DNS 질의, 콘텐츠를 영구 저장하지 않는다.
- 인증·과금 데이터와 네트워크 장애 메트릭을 분리한다.
- 공개 전 법무, 개인정보, 통신사업 신고 여부, 환불, 오픈소스 라이선스를 검토한다.

## 11. 최종 의사결정

Aegis Browser는 개발을 진행할 가치가 있다. 다만 완성형 독자 브라우저를 즉시 만들지 않고, **Windows 전용 자동 보호 브라우저**로 유료 의사를 검증해야 한다. 12주차 폐쇄 베타, 16주차 유료 공개 베타, 24주차 PMF 및 플랫폼 확장 여부를 판단한다.
